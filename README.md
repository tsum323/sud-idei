# AI COURT

Личный AI-суд для идей. Девять AI-агентов независимо рассматривают идею, проводят один раунд
перекрёстной критики, а главный судья выносит вердикт: допустить к реализации, допустить
условно, отправить на доработку или отправить в «Тюрьму идей».

Всё происходит на одном пиксельном экране: нажимаете на персонажа и читаете его заключение.

## Версия для iPad и браузера (claude.ai)

Самый простой способ: страница-артефакт на claude.ai. Она работает в приложении Claude или в
Safari на iPad, без компьютера и без установки. Запросы к Claude идут от вашего имени и
расходуют лимиты вашей подписки Pro. Дела хранятся в хранилище страницы, и читать их можете
только вы.

Сборка и публикация:

```bash
npm run build:artifact   # dist/ai-court.html — одна страница, React с cdnjs
```

Опубликованный файл объявляет две возможности: `sample` (запросы к Claude от имени зрителя) и
`db` (хранилище; правило доступа — читать и писать может только владелец). Логика суда та же,
что и на сервере. Отличия:
- `src/artifact/localApi.ts` заменяет HTTP-клиент, и служба заседаний работает прямо в браузере;
- `src/artifact/memoryStore.ts` — хранилище с тем же поведением, что у SQLite-репозитория; те же
  тесты процесса прогоняются на обоих (`COURT_STORE=memory`);
- `src/artifact/sampleProvider.ts` вызывает Claude через `sample.json`;
- веб-поиска нет: сеть страницы закрыта.

Пока страница открыта, одновременно идут не больше двух запросов (ограничение claude.ai). Если
закрыть страницу посреди заседания, незавершённые этапы помечаются как прерванные; после
повторного открытия нажмите «Продолжить заседание».

## Быстрый старт (локальный сервер)

Приложение работает через вашу подписку **Claude Pro или Max**, без отдельной оплаты. Оно
вызывает установленную у вас программу Claude Code в неинтерактивном режиме (`claude -p`), и
запросы расходуют лимиты подписки.

Нужны **Node.js 22.13 или новее** (хранилище работает на встроенном `node:sqlite`) и Claude Code.

1. Установите Claude Code и войдите в аккаунт с подпиской:
   ```bash
   npm install -g @anthropic-ai/claude-code
   claude auth login
   ```
2. Установите зависимости и запустите приложение:
   ```bash
   npm install
   npm run build && npm start   # http://localhost:3000
   ```
   Файл `.env.local` не обязателен. Он нужен, только если вы хотите поменять модель или
   другие настройки (образец — `.env.example`).

Если Claude Code не установлен или вход не выполнен, приложение показывает, что сделать, и не
запускает заседание. После входа достаточно обновить страницу.

Проверки:

```bash
npm test                                    # тесты; в сеть не ходят
npm run typecheck                           # tsc --noEmit
LIVE_CLAUDE=1 npx vitest run tests/live.test.ts   # 3 настоящих запроса через подписку
```

## Модель и лимиты

```
AI_MODEL=sonnet     # псевдоним Claude Code; можно opus, если он доступен на вашем тарифе
AI_EFFORT=medium    # low — быстрее и экономнее, high — глубже
```

Одно заседание — это 11 запросов: 9 агентов, перекрёстная критика и судья. На Pro лимиты
ограничены, поэтому несколько заседаний подряд могут их исчерпать. Тогда у агентов появится
ошибка «Исчерпан лимит подписки Claude», а уже полученные заключения сохранятся. После сброса
лимита нажмите «Продолжить заседание» — повторятся только незавершённые этапы. Перед запуском
приложение спрашивает подтверждение; это можно отключить в настройках ⚙.

Как устроен вызов:
- **Инструменты отключены.** Claude Code запускается с `--tools ""`, `--strict-mcp-config` и
  `--setting-sources ""`: модель не читает файлы, не выполняет команды, а ваши хуки и
  MCP-серверы не загружаются.
- **Ответ строго по схеме.** Каждый запрос возвращает JSON по схеме (`--json-schema`).
- **Без ключей API.** Из окружения дочернего процесса удаляются `ANTHROPIC_API_KEY` и
  `ANTHROPIC_AUTH_TOKEN`. Иначе Claude Code взял бы ключ, и запросы оплачивались бы по токенам.
- **Свои учётные данные приложение не трогает.** Вход выполняется только через официальную
  команду `claude auth login`.

По правилам Anthropic ([Legal and compliance](https://code.claude.com/docs/en/legal-and-compliance)),
вход через подписку предназначен для обычного личного использования немодифицированного
Claude Code. Сторонним разработчикам запрещено предлагать вход claude.ai в своих продуктах для
других людей. Поэтому приложение рассчитано только на вас: не открывайте к нему доступ другим
людям.

### Вариант с ключом API

Если когда-нибудь понадобится, можно перейти на оплату по токенам:

```
AI_PROVIDER=anthropic-api
ANTHROPIC_API_KEY=sk-ant-...
AI_MODEL=claude-opus-5-5
```

Ключ читается только серверным кодом и в браузер не попадает.

### Веб-поиск (необязательно)

```
SEARCH_PROVIDER=tavily
TAVILY_API_KEY=tvly-...
```

Перед анализом выполняются три поисковых запроса: конкуренты, цены, рынок. Найденные источники
сохраняются как доказательства E1, E2… со ссылкой и датой проверки. Агент может назвать
утверждение «фактом», только сославшись на существующее доказательство. Если ссылки нет, код
понижает утверждение до «предположения». Без поиска отчёт и вердикт прямо указывают, что
актуальные данные не проверялись.

## Как устроено

```
src/
  app/                 Next.js (App Router): страница и API-маршруты
    api/cases/...      создание дела, этапы, вердикт, пересмотр, архив
  components/          интерфейс: сцена, персонажи (SVG-спрайты), панели
  client/              клиентский API и хук управления заседанием (useCourt)
  shared/              общий код: схемы (zod), критерии, расчёт оценок,
                       план заседания, нормализация ответов, построение отчёта
  server/
    ai/                адаптеры модели: Claude Code (подписка), Claude API, ошибки, повторы
    agents/roles.ts    инструкции 9 ролей
    judge/judge.ts     главный судья
    court/             оркестратор процесса и промпты
    evidence/          адаптер веб-поиска
    db/                SQLite-схема и репозиторий
tests/                 тесты vitest; tests/fixtures — тестовый провайдер без сети
```

**Ход заседания.** Каждый этап — отдельный POST-запрос, который клиент вызывает по явному
действию пользователя:

1. `evidence`: веб-поиск, если он настроен.
2. `agents/:agentId`: девять независимых анализов. Клиент запускает их параллельно, по умолчанию
   по три одновременно (меняется в настройках). Результат сохраняется сразу после ответа
   агента. Состояние «Готов» ставится только после сохранения.
3. `cross-exam`: один вызов находит до четырёх самых важных противоречий и оформляет
   контраргументы от лица подходящего агента.
4. `verdict`: судья получает заключения, итоги критики, доказательства и сводку баллов. Общий
   балл считается в коде как взвешенное среднее 10 критериев. Модель выносит решение и объясняет
   вес аргументов. Формальный ориентир по баллам передаётся ей только как справка: одна низкая
   оценка сама по себе не ведёт к отклонению.

**Надёжность.**
- Ошибка одного агента не трогает остальных: агента можно перезапустить отдельно.
- Готовый результат без явного `force` не пересчитывается.
- Повторный одновременный запуск того же агента сервер отклоняет.
- Временные ошибки (429, 5xx, сеть, тайм-аут, неверный JSON) повторяются ограниченное число
  раз (`AI_MAX_RETRIES`). Ошибки входа, исчерпанный лимит подписки и отказы модели не
  повторяются.
- Вызов, который завис после перезапуска сервера, помечается как прерванный, и его можно
  повторить.
- Кнопка «Продолжить заседание» выполняет только незавершённые этапы.
- Если часть агентов завершилась ошибкой, вердикт выносится только по явной кнопке и
  помечается как предварительный.
- Фоновых вызовов модели нет. Пока на сервере идёт вызов, клиент опрашивает только хранилище.

**Хранение.** SQLite-файл `./data/ai-court.db` (путь задаётся в `DATABASE_PATH`). Таблицы:
`cases`, `agents`, `agent_analyses`, `evidence`, `cross_examinations`, `verdicts`,
`action_plans`, `case_events`, `case_stages`. Сущности из ТЗ сохранены, добавлены `round` (номер
заседания) и `case_stages` (состояние этапов для продолжения заседания). Архив и отчёт читаются из
базы, модель для этого не вызывается.

**Тюрьма идей и пересмотр.** Вердикт «Отклонена» переводит дело в статус `prison`. Дело и все
материалы при этом сохраняются. Вернуть идею на пересмотр можно только с описанием новых
оснований, не короче 20 символов. Пересмотр открывает новое заседание (`round + 1`), а прошлые
вердикты остаются во вкладке «История».

## Ограничения

- Через подписку проверены настоящие запросы всех трёх видов (агент, критика, судья) — тест
  `tests/live.test.ts`. Полное заседание из 11 запросов через интерфейс я не запускал, чтобы не
  тратить ваши лимиты: логика этапов та же и покрыта обычными тестами.
- Общий балл — ориентировочная оценка модели, а не вероятность успеха. Вероятности приложение не
  показывает.
- Веб-поиск реализован только для Tavily. Другой поисковик подключается через интерфейс
  `SearchProvider` в `src/server/evidence/search.ts`.
- Приложение рассчитано на локальный запуск для одного пользователя: авторизации нет. Не
  публикуйте его в интернет, иначе кто угодно сможет тратить лимиты вашей подписки.
- `node:sqlite` в Node 22 выводит предупреждение `ExperimentalWarning`. Это ожидаемо и на работу
  не влияет.
